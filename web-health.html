What this page can't check

These tests verify everything reachable from your browser. They cannot verify backend-only logic:

  • Yoco webhook signature verification — only fires when Yoco's server calls your backend after payment
  • Email sending (nodemailer) — only triggers after a successful webhook
  • Cloudinary API credentials — only verified on an actual image upload
  • Price calculation security — whether server.js trusts the browser or recalculates from Firestore

The only real test for those is a live R 2.00 purchase. If all tests here pass but a real purchase fails at the payment step, the bug is in server.js, not the frontend.
